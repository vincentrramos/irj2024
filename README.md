# Replication Files for Ramos and Suguitan (2024) Industrial Relations Journal

**Article:**   [The Incomplete Leap: On the Transition From Union Registration to the First Collective Agreement](https://onlinelibrary.wiley.com/doi/abs/10.1111/irj.12458)

**Journal:**   Industrial Relations Journal

**Date:**      December 2024

**Authors:**   Vincent Ramos and Aidan Suguitan

## Files:

1. **_irj_rep.R**: R codes for all tables and figures

2. **_irj_uniondensity.csv** data file for union densities to replicate Figure 1.
   
3. **_irj_eha.csv** data file for all event history models and descriptive statistics
